# Преподавание сложных тем

GitHub Pages-версия 6-часового методического курса для учителей истории и обществоведения.

## Что загружать в репозиторий

Загрузите в корень репозитория только:

- `index.html`
- `.nojekyll`
- `README.md`

Все учебные материалы остаются в Google Drive:
https://drive.google.com/drive/folders/1UK0XKmOrUvsLB9Aq1ZUFXJor0N2iKXeN

Это сделано намеренно: крупные PDF/PPTX/DOCX не нужны для работы сайта и увеличивают репозиторий.

## Публикация GitHub Pages

1. Создайте новый репозиторий, например `slozhnye-temy`.
2. Загрузите три файла из этой папки.
3. Откройте **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Сохраните.
7. Сайт будет доступен примерно по адресу:
   `https://<ваш-логин>.github.io/slozhnye-temy/`

## Перед занятием

- Проверьте страницу на компьютере и телефоне.
- Проверьте кнопку **«Проверить связь»** в разделе «Рефлексия».
- Отправьте один тестовый ответ.
- Проверьте, что он появился в Google-таблице.
- Проверьте **«Обновить результаты группы»**.
- Убедитесь, что участникам доступна папка Google Drive с материалами.

## Рефлексия

На опубликованной странице ответы отправляются в Google Apps Script через POST.
В таблицу передаются:

- четыре оценки 1–5;
- выбранный достигнутый результат;
- следующий шаг;
- необязательный комментарий;
- случайный идентификатор браузера для обновления повторного ответа.

ФИО и email не запрашиваются.
